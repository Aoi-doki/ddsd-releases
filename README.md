# Doki Doki Second Draft: releases

**Same club. Kinder story.** A wholesome fan mod of Doki Doki Literature Club.

This repository only holds the game's downloads. The **DDSD Launcher** installs and updates the game from here
automatically: download `DDSD-Launcher.exe` from the [latest release](../../releases/latest), run it, and press Install.

- Windows. Needs the original Doki Doki Literature Club (free at [ddlc.moe](https://ddlc.moe)). The launcher finds it for you.
- Work in progress: everything is subject to change.
- Discord: https://discord.gg/FV4pHRJVMU

*Doki Doki Second Draft is a fan mod, not affiliated with Team Salvato. It is free, contains no DDLC files, and
requires you to own DDLC. Doki Doki Literature Club is the property of Team Salvato.*
